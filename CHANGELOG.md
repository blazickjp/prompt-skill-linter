# Release notes

## 1.1.0 — host-assisted workflow release candidate

- Optional local MCP stdio bridge lets an existing coding-agent host propose
  source-grounded contracts without configuring a separate paid API provider.
  Explicit interpretation review remains mandatory; source tools are never run.
- Exact source evidence and assumptions on workflow actions, including visible
  evidence gaps for older contracts.
- Separate source-pinned scientific-workflow corpus runner with review gates,
  immutable inputs, explicit abstentions and natural/control/deployment strata.
- Mandatory official-MCP-SDK CI lane and adversarial protocol regressions.
- Explicit independent action-count and verification-freshness monitors with
  shortest counterexample traces, UNKNOWN on bounds, and a 20,000-state aggregate
  request budget. Source-audited extraction defects have post-audit regressions.

Acceptance remains conditional on the final source-corpus audit and current
snapshot CI. See `docs/REAL_WORKFLOW_ACCEPTANCE.md`. The host adapter does not
certify model extraction, type/data semantics or scientific correctness.

## 1.0.0 — local Studio release (October 10, 2026)

- Local browser workbench, offline installation and one-command launch.
- Source intake with inspectable candidates, explicit acceptance and visible untranslated/excluded coverage.
- Preserved exact synthetic bulk proof; added bounded CNF composition checking, deletion-checked cores and scoped truth tables.
- Prerequisite/effect workflow paths and graphs, unavailable tool-action detection, compliant-fallback distinction and unknown-on-cutoff behavior.

- Optional env-configured OpenAI structured candidate adapter with explicit source/cost consent, exact provenance validation and mock tests; live integration unrun.
- API safety defenses, bounded compute, source-path guards and adversarial regression coverage.
- Versioned scientific/evaluation materials; provisional native-model evidence is not human ground truth or a superiority result.

Release gates are accepted in `docs/PRODUCT.md`. See the linked CI evidence in `docs/STATUS.md`. Live-provider and human-gold gaps remain explicitly outside this acceptance.
