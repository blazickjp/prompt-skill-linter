# Product v1 acceptance

The following gates are accepted for local product v1 on October 10, 2026, within its explicitly documented scope. The optional live provider and future human-gold evaluation are not silently included in that acceptance.

1. Reliable offline installation and one-command local Studio launch, plus the standalone CLI.
2. Source intake produces inspectable extraction candidates, declared/inferred separation, explicit acceptance and verified source provenance. Unsupported prose remains visible rather than silently passing.
3. Exact, conditional bounded-model and semantic diagnostics remain visibly distinct.
4. Bulk-resource, rule-composition and prerequisite/effect workflow examples, including compliant refusal versus unsupported advertised completion.
5. Explicit requirement-changing repair what-if, contract comparison and reproducible regression export; no silent policy changes.
6. Responsive, keyboard-accessible Studio integrated with the real backend, with loading/error/empty states.
7. Versioned independent-source benchmark and measured provisional matched judge pilot, preserving label disagreement, coverage limits and unknown human-ground-truth accuracy.
8. API/security/adversarial tests, isolated source handling, bounded compute, loopback defaults, origin/CSRF defenses and installed-package smoke tests.
9. Quickstart, architecture/model card, release notes and reproducibility instructions.

No paid provider calls, external credentials or public hosted deployment are part of this local release. Publication and CI evidence are coordinated separately. A solver witness is conditional on the reviewed model; no release certifies arbitrary prose, all possible contexts or runtime obedience.
