    MODEL-BASED
    Explore the reviewed model
    Hierarchy, exceptions, Boolean obligations and finite action reachability. Search cutoff means unknown within the bound, never a proof of impossibility.
    SEMANTIC REVIEW
    Keep uncertainty visible
    Ambiguous interpretations are review requests. This tool does not silently translate arbitrary prose or certify an agent will obey instructions.
    How to use the workbench
    1. Load an example or import a JSON bundle with contract, sources, tools and runtime.
    2. Review declared rules, source spans, contexts and assumptions.
    3. Run analysis. Inspect a finding and its evidence.
    4. Pin a baseline. Test an explicit change and compare.
    5. Export the report and reproducible cases.
    Local, deliberately
    Analysis runs in the local Python server. The browser makes only same-origin requests. No external fonts, analytics or arbitrary tool execution. Offline extraction is the default. A configured model provider can receive source text only after explicit consent. Imported text is data, never instructions.
    Unsaved edits live in this browser tab. Export a bundle before closing it.
    Keyboard & evidence
    Ctrl/⌘ + Enter runs analysis. Alt + 1–4 switches views. Every control is keyboard accessible.
    Permission is not obligation. Only enumerated coactive skills and contexts are analyzed. Repairs change named requirements and require renewed review.

    REVIEW-FIRST INTAKE
    Start with the source.
    Paste prompt or skill text. Explicit annotations can become candidate rules. Ordinary prose stays unverified; nothing is accepted silently.
    Model output remains untrusted and requires review. No API key is entered or stored in this browser.
    Supported: REQUIRE / FORBID / PERMIT / PREFER literal = true or false; CLAUSE a | !b
    Accept only the interpretations you have reviewed. Scope defaults to task/run and priority to 0. Excluded and unsupported source lines remain outside the checked contract.
